# news-image-20261124 — The World Today

A program that draws Tuesday 24 November 2026's world news as a
newspaper front page, in one 1024x1024 PNG.

## Run

```sh
python3 main.py   # writes entry.png in the current directory
```

Pure Python 3 standard library only (no network, no clock, no
randomness). Two runs produce byte-identical output.

## The page

- Lead: Nvidia reinstates Jensen Huang as CEO; shares jump 31%,

- Russia's war dead near 500,000, leaked registry data shows
  (The Guardian, Bloomberg, Mediazona).
- Russia may launch a nuclear-armed satellite as soon as December
  (WDR/NDR/Sueddeutsche Zeitung investigation, via Japan Times).
- Virginia and Oregon sue Musk's SpaceX over Grok sexual images
  (Reuters, AP).
- US Rep. Jimmy Gomez to resign on 1 December after an ethics
  finding (CNN, NPR).
- O'Hare ground stop snarls Thanksgiving travel (FAA, NBC Chicago).
- Ticker: UN chief urges global AI safety rules within a year;
  India pledges 15,000 crore rupees in aid and credit to Nepal;
  Burnham on the UK rejoining the EU (UN News, Press Information
  Bureau of India, The Japan Times).

Figures are as reported on 24 November 2026. Where sources
disagree on a number (the Russian death toll), the page gives the
range rather than a single figure.
